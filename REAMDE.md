## To-Do List
A simple Todo List web application built using PHP, MySQL, HTML, and CSS.

## Features
1. Add new tasks
2. Display all tasks
3. Mark tasks as completed
4. Delete tasks
5. Store tasks in MySQL database
6. Simple and clean user interface

## Technologies Used
1. HTML
2. CSS
3. PHP
4. MySQL
5. XAMPP
